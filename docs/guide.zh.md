# Linvell 0.1.6 使用指南

## 启动工作区

在“设置 → 外观 → 启动”中选择“空白欢迎窗口”或“恢复上次的工作区”。恢复模式会重新打开上次的本地文件夹、项目或 SSH 远程文件夹；远程连接沿用当前 SSH 配置与认证。从 Finder 指定打开文件或文件夹时，优先打开该目标，不额外恢复另一个默认窗口。切换为空窗口不会删除上次的工作区记录。启动选择和工作区路径仅保存在本机。左侧活动栏使用底色和侧边指示条标记选中项。

## 远程目录缓存

远程文件夹选择器会打开选中的子目录，无需先进入。选择器与文件树共享目录索引：30 秒内直接复用，过期后先显示缓存并后台刷新。结果未变化时保留列表与选择。手动刷新立即访问远端，刷新失败保留旧列表；文件保存仍检查远端冲突。这些改动减少网络等待，尚未验证所有界面持续达到 120 FPS。

## SSH 远程工作区

从“文件 → 连接 SSH 主机”，或在命令面板搜索“连接 SSH 主机”。Linvell 默认读取 ~/.ssh/config 的具体 Host 别名及 Include 文件；HostName、User、Port、IdentityFile、ProxyJump 和代理等由系统 SSH 解析。

选择主机后，在远程文件夹选择器中浏览并点击“打开此文件夹”。项目树可展开多级文件夹，不会改变项目根目录；通过“打开远程文件夹”切换根目录。取消选择会保留当前工作区。⌘P 搜索根目录下的文件名，最多索引 20,000 个文件。

远程文件协议需要主机提供 POSIX Shell 和 Python 3，Linvell 不安装常驻服务。首次主机密钥确认可在“SSH 终端”完成。文件通道使用非交互 SSH，需可用密钥、SSH Agent 或用户自己配置的 ControlMaster 连接；Linvell 不保存 SSH 密码。

⌘N 新建远程文件，⌘S 保存回原远程路径，保留编码与换行格式。远端文件在读取后发生改动时会阻止覆盖。远程编辑目前支持单文件最大 16 MiB；本地大文件编辑不受此远程限制。临时工作副本保存在受权限保护的本机临时目录。

这套流程支持远程文件、终端、任务和预览转发；目前不运行 VS Code 扩展、Dev Containers，也未提供远程语言服务器／调试适配器宿主。

## 运行、停止、日志与网页预览

打开“视图 → 运行与预览”（⇧⌘B），选择检测到的任务或输入命令，再点“运行”。本地任务使用本地项目目录，SSH 任务在当前远程目录和远程主机中运行；不会仅因为项目存在任务文件就自动执行。

终端实时显示输出并接受交互输入。“停止”先发送中断，再关闭仍未退出的任务；关闭工作区前会询问是否停止运行中的任务。任务退出后面板保留日志。

本地可检测 npm 脚本、Swift 运行／测试、Make 及 .vscode/tasks.json 中基础的字面命令任务；远程可检测 npm 脚本、Swift 和 Make。VS Code 的高级任务依赖、问题匹配器和变量展开尚未导入，请直接输入展开后的命令。

输入 HTTP 或 HTTPS 地址后点“预览”。远程服务请输入远端的 localhost 地址，例如 http://127.0.0.1:3000。Linvell 自动选择空闲本地端口，SSH 转发仅绑定 127.0.0.1；关闭运行器／工作区会关闭转发。

## Git 管理与 Git Graph

打开本地仓库文件夹，选择“源代码管理”（⌃⇧G）、“视图 → Git 提交图谱”或命令面板中的“Git 提交图谱”。三栏分别显示分支、改动／提交图谱和差异详情；改动列表以可读标签显示文件状态。

“暂存／取消暂存”作用于选中文件。对于已跟踪文本文件的差异，可选择变更块并执行“暂存此块／取消暂存此块”，只改变暂存区中的这一部分；工作区文件保持原样。“提交”只提交已有暂存改动。“获取”、仅快进“拉取”和“推送”使用仓库已有认证。

“提交图谱”根据真实父提交关系绘制所有引用范围内最多 150 条提交的分叉与合并节点，并显示分支／标签。选择提交可查看元数据及补丁；双击分支可切换，“分支”入口也可创建指定分支。

Git 面板支持本地与 SSH 工作区，远程操作使用所选主机的 Git 和已有 SSH 认证；本版不包含 Sublime Merge 的全部历史改写操作或三方冲突编辑器。仅浏览文件树不会执行 Git；暂存、提交、推送等写操作由对应按钮触发。

## 多选、多替换与列编辑

⌥单击追加光标；⌘D 选中下一个同词；先按 ⌘K 再按 ⌘D 跳过当前匹配；⇧⌘L 选中全部匹配；⌘U 撤销最近一次选区扩展。

输入、删除、剪切或粘贴会作用于全部选区。粘贴内容的行数恰好等于选区数时按顺序分配，否则每处插入完整内容；多位置修改作为事务支持撤销／重做。

⇧⌥拖动创建矩形选区；⇧⌥⌘加方向键用键盘扩展列选区；⌥⌘↑／↓ 在上／下方追加光标；⇧⌥I 将选区按行拆开。列选保持 Tab 和字素完整，单次最多 10,000 行。

## Vim 可视与多位置编辑

在设置中启用 Vim。v 进入字符可视模式，V 进入可视行模式，⌃V 进入可视块模式；使用 h/j/k/l、w/b、0/$ 或 G 移动，Esc 回到普通模式。

在可视／块选区中，d 或 x 删除，c 在选中位置修改，y 复制，r 替换所选字符，I／A 在所选行起点／终点进入插入。

已有多个光标时，普通模式支持广播移动、i/a/I/A、x、c/d 配合 w/$ 或重复操作符、r、y、p 及撤销／重做。多光标插入模式按一次 Esc 保留光标并回普通模式，再按一次 Esc 合并光标；普通多选快捷键仍然可用。

纯 Swift 实现尚未达到完整 Vim 兼容。完整正则／Ex、映射、可视／替换模式宏、完整块寄存器和部分复合操作仍在开发中。当前不提供 Vimscript／Vim9 或 VSIX 扩展宿主。

Swift 引擎支持次数与操作符组合（2d3w）、单词／括号／引号文本对象（ciw、ci(、da"）、f/F/t/T 与分号／逗号重复、命名寄存器、标记、r、J 和点号重复。R 按字素覆盖，退格恢复被覆盖内容；插入会话可作为一次修改撤销。

使用 qa 录制普通／插入模式宏，q 停止，@a 回放，@@ 重复；状态栏显示录制状态。可视选择支持文本对象和带次数移动，多光标可同时执行 ci(、2dw 等操作。

使用 / 或 ? 正向／反向查找，n/N 重复，*/# 查找完整单词。:s/foo/bar/ 替换当前行第一个匹配；:%s/foo/bar/g 替换所有匹配；:2,5s/foo/bar/g 限制行范围。捕获组使用 Vim 风格的转义括号及替换反向引用；尚未支持的原子或参数会先报错，不会静默修改。

Markdown 源码与右侧预览双向同步滚动；切换预览时保留文档位置。更新器仅保留一个压缩的回滚版本，旧隐藏应用副本会自动迁移。

## 目录选择与刷新节奏

单击选中远程子目录后直接点打开，目标就是该子目录；双击进入后再打开，目标相同。原生滚动区域启用 AppKit 响应式滚动，终端绘制使用窗口显示回调。回调间隔本身不能证明滚动画面的实际呈现帧率。上面的目录缓存减少网络等待和重复列表重载，持续高刷的实际呈现仍在排查。
