# 原生代码智能与最近项目

代码智能由 Swift 原生语言客户端协调：能力协商、完整／增量文档同步、协议级取消、文件变化通知、服务分析进度、推送／拉取诊断和共享服务生命周期。本地与 SSH 项目的设置统一放在窗口顶部项目名旁，项目工具读取所属主机。配置一致的 JavaScript／TypeScript 共用一个进程，最后一个相关文件关闭后释放服务与监视器。可在 .linvell/settings.json 的各语言分区中使用 linvell.languageServerSettings 配置服务。

F12 转到定义，Shift-F12 查找引用；Option-左／右返回／前进，保留 Control-minus／Control-Shift-minus。Command-Shift-O 搜索文档符号，Command-T 通过语言服务搜索工作区符号。Command-F12 转到实现，“前往”菜单也提供声明与类型定义。Control-Space 补全，Command-Shift-Space 参数提示，F2 语义重命名，Option-Shift-F 格式化，Command-Shift-M 打开“问题”。具体能力取决于所选服务，导入别名遵循对应语言的作用域。

鼠标悬浮提示卡片不抢键盘焦点，离开符号、滚动、输入或切换窗口即关闭。迟到的 SSH 读取结果不会在返回后抢回编辑器。欢迎页最多显示十二个最近项目及路径，SSH 项目带“远程”前缀与主机，点击后在当前窗口重开。历史记录只保存在本机。远程文件监视在后台运行，索引未变化时只返回摘要，不重复传输整份元数据。

语义分析限制为单文件 2 MiB，重命名最多 500 文件／32 MiB，远程源文件监视最多 20,000 文件。新建未保存缓冲区需要文件路径才能进行项目分析。“已连接”表示服务连接状态，索引进度来自后端报告。旧版本只保留了上次工作区，这条记录会迁入新的历史列表。
