Built in the open.

Linvell is in early development. The native editing workspace is available; the complete editor is still being built.

GitHub ReleasesView source

Signed version 0.1.5 is available from GitHub Releases.

Available now

  • Native AppKit workspace, file tree, tabs, shared-buffer editor splits and adjustable text size.
  • Text editing with encoding and line-ending preservation, external-change protection and local recovery snapshots.
  • A real PTY terminal powered by SwiftTerm, plus an initial Swift Vim command engine.

Four built-in themes

Linvell Dark, Nord, Linvell Light and Solarized Light. Choose your theme in View → Theme. The editor starts at 15 pt; use ⌘+ and ⌘− to find your own rhythm.

Preferences, with a sync switch

Settings → Sync includes an iCloud Drive switch. Theme, font, text size, wrapping, line numbers, indentation and Vim mode can follow you between Macs. Turn it off to keep preferences local. Documents, recovery snapshots and credentials stay on your Mac. Cross-Mac delivery still needs multi-device validation.

Remote development and Git

SSH remote files and terminal, local/remote run with web preview forwarding, Git management and Git Graph, plus rectangular and Vim block selections.

Still ahead

Full Vim compatibility, language services, debugging, a VS Code extension host and advanced Git history editing remain in development. See the usage guide for the exact supported workflows and limits.

Download and trust

Distribution is through GitHub Releases, outside the Mac App Store. Each release lists its architecture, signing and notarization status, known limitations and SHA-256 checksums. Download only from the official release page.

Linvell does not include analytics, accounts or a plugin marketplace. Recovery snapshots stay on your Mac. The website uses local storage only to remember your language preference.

Native by design. Deliberate by nature.
