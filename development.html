Built in the open.

Linvell is under active development. This page describes features shipped through 0.2.10, checked on October 31, 2026. The complete editor remains in development.

Available now

  • Native AppKit workspace with a hierarchical explorer, tabs, shared-buffer split editors and resizable panes. Image, Markdown and HTML previews include local assets; Markdown source and preview scroll together.
  • Encoding and line-ending preservation, atomic saves, external-change protection and local recovery snapshots. Recovered text opens as an untitled copy.
  • Find/replace, bounded project text search, document symbols, multiple carets, rectangular column selections and distributed multiline paste, with transactional undo/redo.
  • A Swift Vim engine with Normal, Insert, Visual, Visual Line, Visual Block and Replace modes; composed counts/operators, text objects, registers, marks, dot repeat, normal/insert macros and bounded Vim-pattern search/substitution. Full Vim compatibility is not claimed.
  • SwiftTerm PTY terminal, read-only runtime/package manifest tools and native system metrics. Package modifications, database tools and task chains remain open.

Appearance and preferences

Choose Linvell Dark, Nord, Linvell Light or Solarized Light in Settings → Appearance. The editor starts at 15 pt, supports installed monospace fonts and the native font chooser, and switches the UI between Chinese and English. Startup can open an empty window or restore the last local or SSH folder.

Remote development, running and Git

  • SSH workspaces provide folder browsing, new files, editing, conflict-aware saves, filename search and a terminal using existing system SSH configuration. The remote file protocol requires a POSIX shell and Python 3; remote files are limited to 16 MiB.
  • Run/stop local or remote commands with live PTY output and WebKit web preview. SSH preview forwarding binds only to local loopback. Advanced VS Code task dependencies and variable expansion are not imported.
  • Local and SSH Git workspaces share working/index diffs, file and hunk staging, commits, branches, fetch, fast-forward pull and push. Git Graph shows actual parent links for up to 150 commits.

Recent progress: 0.1.7–0.2.10

  • 0.1.7–0.1.9 added lexical highlighting, structural folding, relative line numbers, optional conflict-safe auto-save, project language tools, native language-service navigation/completion/rename, recent projects and native Git/submodule operation forms.
  • 0.2.0–0.2.3 introduced native plugin APIs, LSP/task/DAP integration and SSH plugin execution, followed by persistent installation, enable/disable, configured catalogs, explicit updates, rollback and uninstall. Homebrew distribution and installation-source-aware updates are available.
  • 0.2.4–0.2.7 integrated existing Codex, OpenCode, Pi, Claude Code and DSH installations, with project/local/SSH session discovery, independent concurrent terminals and restoration of the selected provider, host and session.
  • 0.2.8 replaced the SSHFS/macFUSE path with optional Mutagen replicas for local agents editing SSH projects. Two-way-safe synchronization preserves conflicts; clean editor buffers refresh after external changes, while dirty edits remain protected.
  • 0.2.10 shows newly opened Agent sessions immediately in the sidebar, updates titles and reuses running terminals. DSH uses a separately installed compatible TUI instead of the embedded website. Missing CLI/TUI installations show guidance; startup duplication, terminal layout and resumed-session readiness were corrected.

Optional iCloud preference sync

Settings → Sync controls iCloud Drive sync for theme, font, text size, wrapping, line numbers, indentation and Vim mode. Settings merge independently. Documents, recovery snapshots, workspace paths and credentials stay local. Two-Mac delivery and concurrent-edit acceptance remain pending.

Still ahead

  • Complete Vim regex/Ex, remapping, block-register semantics, visual/Replace macros and some compound multi-cursor operations remain open. A minimap, complete debugger compatibility and a graphical three-way merge editor are not provided. Native folding, language services, DAP launch support and Git operation forms are already available; their scope depends on the configured tools. Vimscript/Vim9 and VS Code extension hosting are not provided.
  • Full file/split/cursor session restoration, encoding conversion UI, explicit mixed-line-ending normalization, project replacement previews and cancellation-aware large-project indexing/search. Existing search and file limits still apply.
  • Large-file benchmarks, sustained high-refresh presentation, Intel runtime acceptance, input-method coverage and accessibility auditing remain open. Local real-account Agent acceptance covers Codex and DSH; other providers have fixture coverage, and remote real-account TUI acceptance remains untested. Universal compilation and a signed release do not establish complete product acceptance.

Download and trust

Download the signed, notarized Universal app from GitHub Releases or the Linvell-maintained Homebrew tap. Manual installations use the in-app updater, which checks SHA-256, signing identity and the newer version. Homebrew installations update through their Cask source. Review each release’s manifest and known limitations; Linvell is not distributed through the Mac App Store.

Linvell has no built-in model account system or analytics. Plugins can be installed from local packages, HTTPS URLs and configured catalogs; code plugins run with the user’s OS access. Recovery snapshots stay on your Mac. The website uses local storage only to remember your language preference.
